# SPEC — 층 결합 연구 (심층학습 기말 프로젝트, Track A)

> 상태: `ready-for-agent`

## 문제 정의 (Problem Statement)

우리 팀(2인: 모델 담당 고용민, 인프라 담당 차가원)은 "고정된 ModernBERT-base의 여러 층 표현을 어떻게 결합하느냐에 따라 분류 오차율이 얼마나 달라지는가, 그리고 그 효과가 데이터 양·백본 학습 여부·과제·입력 길이에 따라 어떻게 달라지는가"라는 연구 질문에 12/14 최종 발표까지 답해야 한다.

평가의 55%가 방법론(실험 설계의 엄밀성 30% + 결과 분석과 해석 25%)이고, PDF는 변인 통제·반복 실험·동일 튜닝 예산·오차율/파라미터 수/학습 시간 동시 보고·"차이 < 표준편차면 효과 없음"을 요구한다. 지금은 코드가 없고, 설계 결정(ADR 0001~0009)만 있다. 이 결정들을 지키지 않는 코드가 결과표에 섞이면 다음 같은 문제가 생긴다.

- 결합 방식마다 튜닝 예산·표본·시드가 달라져 비교가 불공정해진다.
- 층 출력 척도 차이(pre-norm, 마지막 값만 최종 정규화) 때문에 **층 가중치**가 "값이 커서" 커진 것을 "정보가 유용해서"로 잘못 해석한다.
- 여러 실행이 한 GPU를 나눠 써서 **학습 시간**을 설정끼리 비교할 수 없다.
- **디버깅 실행**이나 **재현 트랙** 수치가 본 실험 결과표에 섞인다.
- 결과를 본 뒤 판정 기준을 바꿨다는 의심을 받는다.
- 층 벡터 캐시가 다른 설정(길이·자르기·버전)으로 만들어졌는데 모르고 재사용한다.

## 해결 (Solution)

하나의 실험 파이프라인을 만든다. 사용자는 **실행 설정**(데이터셋, **데이터 양 조건**, **결합 방식**, 백본 조건, **입력 설정**, 시드, 학습률)을 고르면, 파이프라인이 ADR의 통제 규칙을 지킨 채로 **결과 레코드**를 만든다. 결과 레코드들은 **판정 규칙 문서**와 함께 판정 모듈에 들어가 가설별 판정표(지지 / **효과 없음**)와 보고서용 표·그림을 만든다.

- **백본 고정 조건**이 기본이다. **층 벡터**를 한 번만 추출해 캐시하고, 결합 방식과 분류기만 학습한다(ADR 0004).
- **파인튜닝 조건**은 MNLI 핵심 비교(B0 vs 가장 좋은 결합 방식)에만 쓴다(ADR 0004).
- **재현 트랙**(논문 공개 정확도 MNLI 89.1, SST-2 96.0 — 오차율로는 10.9%, 4.0%)은 별도 실행 묶음이며 본 실험 결과와 섞지 않는다(ADR 0004).
- **본 실험 실행**은 인프라 담당 한 사람이 대기열로 한 번에 하나씩 돌린다. **디버깅 실행**은 각자 동시에 돌려도 되지만 결과표에 들어가지 않는다(ADR 0009).
- 판정 기준은 11/30에 판정 규칙 문서로 고정하고, 결과를 본 뒤에는 바꾸지 않는다(ADR 0007).

## 사용자 스토리 (User Stories)

행위자: **모델 담당**(결합 방식·분류기·분석), **인프라 담당**(서버·대기열·캐시·실행), **팀**(두 사람 모두), **평가자**(교수님·보고서 독자).

### 데이터 준비

1. 모델 담당으로서, MNLI·SST-2·IMDB를 같은 방식으로 불러오고 싶다. 그래야 데이터셋마다 다른 전처리 실수가 생기지 않는다.
2. 모델 담당으로서, MNLI의 두 문장을 [SEP]으로 이어 붙인 **하나의 입력**으로 넣고 싶다. 그래야 ADR 0001대로 SST-2와 결합 구조가 같아지고 GLUE 공개 수치와 비교할 수 있다.
3. 모델 담당으로서, 학습셋의 10%를 **튜닝 분할**로 떼어 학습률을 고르는 데에만 쓰고 싶다. 그래야 학습률을 고를 때 **평가셋**을 보지 않는다.
4. 모델 담당으로서, MNLI·SST-2는 공개 validation을, IMDB는 test를 **평가셋**으로 쓰고 싶다. 그래야 GLUE 테스트 정답이 비공개인 문제를 피하고 논문 수치와 조건이 같아진다.
5. 모델 담당으로서, MNLI 평가셋을 **matched 평가셋**과 **mismatched 평가셋**으로 나눠 따로 오차율을 받고 싶다. 그래야 추가 학습 없이 H4′를 판정할 수 있다.
6. 모델 담당으로서, **데이터 양 조건** "소량"을 고르면 클래스당 1,000건만 쓰게 하고 싶다. 그래야 H2를 같은 파이프라인으로 검증할 수 있다.
7. 모델 담당으로서, 소량 표본이 시드마다 새로 뽑히되 같은 시드 안에서는 모든 결합 방식이 같은 표본을 쓰게 하고 싶다. 그래야 ADR 0007의 공정 비교 규칙을 지킨다.
8. 모델 담당으로서, 소량 표본에 뽑힌 문서 ID 목록을 결과와 함께 남기고 싶다. 그래야 "같은 시드 안에서 같은 표본이었다"를 보일 수 있다.
9. 모델 담당으로서, 모든 문서에 문서 ID를 붙이고 싶다. 그래야 캐시·예측값·McNemar 짝짓기가 문서 단위로 맞춰진다.
10. 인프라 담당으로서, 교수님이 SST-2를 승인하지 않으면 SST-2를 설정에서 빼기만 하면 되게 하고 싶다. 그래야 나머지 실험 계획이 흔들리지 않는다.
11. 인프라 담당으로서, MNLI가 거절되면 AG News로 바꿀 수 있게 하고 싶다. 그래야 ADR 0003의 비상 계획을 따를 수 있다.

### 입력 길이 (IMDB)

12. 모델 담당으로서, IMDB에 **입력 설정** L128 / L512 / Lfull 중 하나를 고르고 싶다. 그래야 ADR 0006의 길이 비교를 할 수 있다.
13. 모델 담당으로서, L128은 **앞+뒤 자르기**로 앞 32 + 뒤 94 토큰, L512는 앞 128 + 뒤 382 토큰을 남기고, 특수 토큰을 포함해 각각 128 / 512가 되게 하고 싶다. 그래야 세 설정의 차이가 길이 하나로 한정된다.
14. 모델 담당으로서, **Lfull**에서는 상한까지 자르지 않고 문서 전체를 넣고 싶다. 그래야 긴 입력의 효과(H5a)를 L512와 비교할 수 있다.
15. 인프라 담당으로서, IMDB 전체를 ModernBERT 토크나이저로 세어 최대 길이를 알고 싶다. 그래야 Lfull 상한(4,096 이하면 자르지 않음, 넘으면 4,096 유지)을 정할 수 있다.
16. 모델 담당으로서, Lfull 상한 때문에 잘린 문서가 있으면 그 비율을 받고 싶다. 그래야 보고서에 적을 수 있다.
17. 모델 담당으로서, 모든 IMDB 문서에 토큰 길이와 **길이 구간**(≤512 / 512~1,024 / 1,024 초과)을 붙이고 싶다. 그래야 L512 vs Lfull을 길이 구간별로 보고할 수 있다.
18. 모델 담당으로서, 문서별 **시야 비율**을 계산해 길이 구간별로 제시받고 싶다. 그래야 시야 비율을 숫자 하나가 아닌 구간별로 보고할 수 있다.
19. 모델 담당으로서, L128의 평균 시야 비율을 확인하고 싶다. 그래야 보고서의 "지역 층이 입력 대부분(평균 약 75%)을 보는 대조군" 표현이 근거를 갖는다.
20. 평가자로서, 길이 구간마다 문서 수를 함께 보고 싶다. 그래야 최소 표본 기준과 견주어 결론을 얼마나 믿을지 판단할 수 있다.

### 층 벡터 추출과 캐시

21. 인프라 담당으로서, 층 벡터를 한 번만 추출해 캐시하고 싶다. 그래야 백본 고정 조건의 시드 반복이 값싸다.
22. 모델 담당으로서, 입력 하나당 **층 벡터** 23개(**임베딩 벡터** 1개 + 22개 층)를 받고 싶다. 그래야 모든 결합 방식이 같은 재료를 쓴다.
23. 모델 담당으로서, 층 벡터를 패딩을 뺀 토큰 평균으로 만들고 싶다. 그래야 배치 안의 패딩 양이 벡터에 섞이지 않는다.
24. 모델 담당으로서, 고정한 transformers 버전에서 23번째 층 벡터가 최종 정규화를 거친 **마지막 층 벡터**인지 1주차에 확인받고 싶다. 그래야 ADR 0005의 전제가 실제 버전에서 맞는지 알 수 있다.
25. 인프라 담당으로서, 캐시 파일에 생성 설정(모델, 버전, 길이, 자르기 방식)을 기록하고 싶다. 그래야 어떤 설정으로 만든 캐시인지 알 수 있다.
26. 인프라 담당으로서, 실행 설정과 캐시 생성 설정이 다르면 실행이 오류로 멈추게 하고 싶다. 그래야 다른 설정의 캐시를 모르고 재사용하는 사고를 막는다.
27. 모델 담당으로서, 캐시 형태가 [문서 수, 23, 768]이고 문서 ID·라벨 순서가 원본 데이터와 일치하는지 확인받고 싶다. 그래야 예측값과 정답이 어긋나지 않는다.

### 층별 정규화와 결합 방식

28. 모델 담당으로서, 모든 결합 방식·모든 데이터에서 결합 전에 **층별 정규화**(학습 파라미터 없는 LayerNorm)를 적용하고 싶다. 그래야 층 가중치가 척도 때문에 왜곡되지 않는다.
29. 모델 담당으로서, **B0**를 고르면 **마지막 층 벡터**(백본 안에서 최종 정규화된 토큰 출력을 패딩 제외 토큰 평균한 벡터)만 층별 정규화 후 선형 분류기에 넣고 싶다. 그래야 기준선이 ADR 0004·0005의 정의와 같다.
30. 모델 담당으로서, **F1**을 고르면 모든 층 벡터를 같은 비중으로 평균하고 싶다. 그래야 학습 가중치 없이 **섞기 효과**를 볼 수 있다.
31. 모델 담당으로서, **F2**를 고르면 층마다 가중치 하나를 데이터셋 전체에 대해 학습해 가중합하고, 전체 스케일 계수 γ는 두지 않고 싶다. 그래야 ADR 0005를 지키고 **가중치 학습 효과**를 분리할 수 있다.
32. 모델 담당으로서, **F3**를 고르면 마지막 4개 층의 층 벡터를 이어붙이고 싶다.
33. 모델 담당으로서, **F4**를 고르면 입력마다 층 가중치가 달라지는 결합을 학습하고 싶다. 그래야 입력별로 기대는 층이 달라지는지 볼 수 있다.
34. 모델 담당으로서, **B0+**를 고르면 마지막 층 벡터만 쓰는 2층 MLP(은닉 크기 MNLI 26)를 학습하고 싶다. 그래야 "파라미터가 많아서 이겼다"는 반론에 답할 수 있다.
35. 모델 담당으로서, 결합 방식별 학습 파라미터 수를 결과에 넣고 싶다. 그래야 결과표 옆에 파라미터 수 표를 붙일 수 있다(ADR 0008).
36. 모델 담당으로서, B0+와 F4의 학습 파라미터 수가 맞춰져 있는지 확인받고 싶다. 그래야 대조군이 설계 의도대로 만들어졌음을 보장한다.
37. 모델 담당으로서, F2를 **전역 층** 8개만 / **지역 층** 14개만으로 학습하는 ablation을 하고 싶다(임베딩 벡터는 양쪽에서 제외). 그래야 H5c를 보조 확인할 수 있다.
38. 모델 담당으로서, 층 번호별 전역/지역 여부와 **층 범위**(하위 1~7, 중간 8~15, 상위 16~22)를 한 곳에서 정의하고 싶다. 그래야 ablation과 해석이 같은 정의를 쓴다.

### 학습과 튜닝 예산

39. 모델 담당으로서, 모든 결합 방식에 학습률 후보 3개·같은 에폭 수·같은 조기 종료 기준을 쓰게 하고 싶다. 그래야 "한쪽만 많이 튜닝"했다는 지적을 피한다.
40. 모델 담당으로서, 튜닝 분할에서 고른 학습률로 시드를 반복하고 싶다. 그래야 평가셋을 튜닝에 쓰지 않는다.
41. 모델 담당으로서, 학습률 선택 결과를 남기고 싶다. 그래야 튜닝 예산이 같았음을 보고서에 보일 수 있다.
42. 모델 담당으로서, 학습 곡선을 그릴 수 있게 학습 중 지표를 기록하고 싶다. 그래야 PDF가 요구하는 학습 곡선을 보고할 수 있다.
43. 모델 담당으로서, 핵심 비교는 5시드, 나머지는 3시드로 돌리고 싶다. 그래야 ADR 0007의 반복 규칙을 지킨다.

### 파인튜닝 조건과 재현 트랙

44. 모델 담당으로서, MNLI에서 B0와 가장 좋은 결합 방식을 **파인튜닝 조건**으로도 돌리고 싶다. 그래야 H3를 판정하고 파인튜닝 대비 향상폭을 보일 수 있다.
45. 인프라 담당으로서, **재현 트랙**을 논문 설정 그대로(전체 데이터 파인튜닝, 3회) 돌리고 싶다. 그래야 논문 공개 수치(정확도 MNLI 89.1 / SST-2 96.0, 오차율 10.9% / 4.0%)와 우리 재현 수치를 비교할 수 있다.
46. 평가자로서, 재현 트랙 결과를 본 실험 결과와 따로 보고 싶다. 그래야 논문 분류 헤드 결과와 B0(층별 정규화 + 선형 분류기)가 섞이지 않는다.

### 실행 관리

47. 인프라 담당으로서, 본 실험 실행을 대기열로 한 번에 하나씩 돌리고 싶다. 그래야 학습 시간을 설정끼리 비교할 수 있고, 연구실 공용 서버에서 다른 작업과 겹치지 않는다.
48. 인프라 담당으로서, 본 실험 실행과 디버깅 실행을 구분해 기록하고 싶다. 그래야 디버깅 결과가 결과표에 들어가지 않는다.
49. 팀으로서, 디버깅 실행은 각자 계정에서 동시에 돌리고 싶다. 그래야 개발 속도가 떨어지지 않는다.
50. 인프라 담당으로서, 본 실험 실행에 사용한 transformers 버전·어텐션 구현·컴파일 설정을 결과에 남기고 싶다. 그래야 ADR 0005의 고정이 지켜졌음을 보일 수 있다.
51. 팀으로서, 일정이 밀리면 MNLI > SST-2 > IMDB 순으로 실행 우선순위를 주고 싶다. 그래야 1~4순위 가설(MNLI)이 먼저 지켜진다.

### 결과 레코드

52. 모델 담당으로서, 실행 하나가 끝나면 결과 레코드 하나(실행 설정, 평가셋 오차율, 문서별 예측값, 학습 파라미터 수, 학습 시간, 학습 곡선, 학습률 선택 결과, 층 가중치, 실행 종류)를 받고 싶다. 그래야 분석을 결과 레코드만으로 할 수 있다.
53. 모델 담당으로서, 결과 레코드에 문서 ID별 예측과 정답을 남기고 싶다. 그래야 McNemar 검정과 길이 구간별 오차율을 계산할 수 있다.
54. 모델 담당으로서, F2 실행에서는 층 가중치를, F4 실행에서는 문서별 층 가중치를 결과 레코드에 남기고 싶다. 그래야 무게중심·전역 층 가중치 비율을 계산할 수 있다.

### 판정과 분석

55. 팀으로서, 11/30에 판정 규칙 문서(판정 기준, 최소 표본 기준, 시드 일관성 기준값)를 고정하고 싶다. 그래야 결과를 본 뒤 기준을 바꿨다는 의심을 받지 않는다.
56. 모델 담당으로서, 판정 모듈이 고정된 판정 규칙 문서를 읽어 판정하게 하고 싶다. 그래야 판정 기준이 코드 안에 따로 흩어지지 않는다.
57. 모델 담당으로서, 두 설정의 오차율 차이가 시드 간 표준편차보다 작거나 McNemar 검정이 유의하지 않으면 "효과 없음"으로 판정받고 싶다. 그래야 PDF 해석 원칙과 ADR 0007을 함께 지킨다.
58. 모델 담당으로서, McNemar 검정을 같은 문서끼리 짝지어 계산하고 싶다. 그래야 평가셋이 작아서 생기는 흔들림도 반영된다.
59. 모델 담당으로서, **확증 가설**(H1, H3, H2, H4′, H5b, H5a)은 "지지 / 효과 없음"으로, **탐색적 가설**(H4, H5c)은 판정 없이 경향만 받고 싶다. 그래야 가설 성격이 결과표에서 섞이지 않는다.
60. 모델 담당으로서, H1(백본 고정 시 층 결합이 B0보다 낫다, MNLI) 판정을 받고 싶다. 그래야 연구 질문의 본체에 답할 수 있다.
61. 모델 담당으로서, H3(파인튜닝하면 결합 효과가 줄거나 사라진다, MNLI) 판정과 파인튜닝 대비 향상폭을 받고 싶다.
62. 모델 담당으로서, H2(소량 데이터에서 효과가 더 크다, MNLI) 판정을 받고 싶다. 그래야 "언제 효과가 있나"에 답할 수 있다.
63. 모델 담당으로서, H4′(처음 보는 장르에서도 유지된다, MNLI mismatched) 판정을 받고 싶다.
64. 모델 담당으로서, H5a(긴 입력 자체의 효과)와 H5b(긴 입력의 이득이 층 결합에서 더 크다, F2로 판정하고 F1은 보조) 판정을 L512 vs Lfull 길이 구간별로 받고 싶다.
65. 모델 담당으로서, H5b를 섞기 효과(F1 − B0)와 가중치 학습 효과(F2 − F1)로 나눠 보고받고 싶다. 그래야 이득이 어디서 오는지 설명할 수 있다.
66. 모델 담당으로서, ≤512 길이 구간에서 L512와 Lfull 결과가 같은지 확인받고 싶다. 그래야 파이프라인이 정상 작동함을 보일 수 있다.
67. 모델 담당으로서, 길이 구간별 결과에 최소 표본 기준을 적용받고 싶다. 그래야 표본이 적은 구간에서 과한 결론을 내리지 않는다.
68. 모델 담당으로서, 층 가중치로 **무게중심**과 **전역 층 가중치 비율**을 계산받고 싶다. 그래야 H4·H5c를 층 가중치로 볼 수 있다.
69. 모델 담당으로서, 층 가중치를 해석하기 전에 **시드 일관성**(시드 간 순위 상관, 무게중심의 시드 간 표준편차)을 검사받고, 기준에 못 미치면 해석을 보류하고 싶다.
70. 모델 담당으로서, H4(탐색적)는 MNLI와 SST-2의 층 가중치(무게중심) 경향으로 비교하고, SST-2 오차율 비교에는 McNemar 검정을 쓰고 싶다. 그래야 SST-2 평가셋(872건)의 흔들림에 휘둘리지 않는다.
71. 모델 담당으로서, 전역 층만 / 지역 층만 F2 ablation의 결과를 입력 설정별로 받고 싶다. 그래야 H5c를 보조 확인할 수 있다.
72. 모델 담당으로서, Lfull F4에서 문서 길이와 문서별 전역 층 가중치 비율의 순위 상관을 전체·라벨별로 받고 싶다. 그래야 "게이트가 길이에 반응한다"까지 말할 수 있다.
73. 평가자로서, 결합 방식별 "오차율 평균 ± 표준편차 / 파라미터 수 / 학습 시간" 결과표를 보고 싶다. 그래야 PDF의 결과 보고 형식이 충족된다.
74. 평가자로서, 표·그래프·해석 세 가지가 짝지어진 보고를 보고 싶다. 그래야 PDF의 "기본 보고" 요건이 충족된다.
75. 평가자로서, 보고서 한계 절에 B0+의 형태 차이, 전역/지역 층 수 차이(8 vs 14) 가정, 지역 층이 전역 층 출력을 입력으로 받는다는 점, 선행연구와의 비교가 정성 비교라는 점을 보고 싶다. 그래야 결론의 범위를 정확히 이해한다.

## 구현 결정 (Implementation Decisions)

### 모듈 구성

바깥 경계는 **실행 seam**과 **판정 seam** 두 개로 둔다(팀 확인).

1. **데이터 모듈** — 데이터셋과 분할을 받아 (문서 ID, 입력 텍스트, 라벨) 목록을 돌려준다. MNLI는 장르(matched/mismatched)도 낸다. 튜닝 분할(학습셋의 10%) 떼기와 소량 표본 추출(시드마다 새로 뽑고, 같은 시드 안에서는 모든 결합 방식이 같은 표본)을 맡는다.
2. **입력 구성 모듈** — 문서와 입력 설정을 받아 토큰 ID를 돌려준다. MNLI는 두 문장을 [SEP]으로 이은 하나의 입력. IMDB는 앞+뒤 자르기(L128: 32+94, L512: 128+382, 특수 토큰 포함 128/512)와 Lfull 상한을 적용하고, 토큰 길이와 길이 구간을 함께 낸다.
3. **층 구조 정의** — 층 번호(임베딩 벡터 + 1~22층)별 전역/지역 여부와 층 범위를 한 곳에서 정의한다. 전역 층은 첫 층과 마지막 층을 포함해 3층마다 하나(1, 4, 7, 10, 13, 16, 19, 22층)인 8개, 나머지 14개는 지역 층이다.
4. **층 벡터 추출기** — 입력마다 층 벡터 23개를 패딩 제외 토큰 평균으로 만들어 캐시에 쓴다. 마지막 값은 최종 정규화된 출력이다(ADR 0005, 1주차 재확인). 캐시는 [문서 수, 23, 768] + 문서 ID·라벨 순서 + 생성 설정(모델, 버전, 길이, 자르기 방식)으로 이루어진다.
5. **층 벡터 공급원(인터페이스)** — 실행 모듈이 층 벡터를 받는 통로. 캐시 공급원(백본 고정), 백본 공급원(파인튜닝), 테스트용 가짜 공급원을 주입할 수 있다. 공급원의 생성 설정이 실행 설정과 다르면 오류를 낸다.
6. **결합 헤드** — 층 벡터를 받아 층별 정규화 → 결합 방식 → 분류기 순으로 로짓을 낸다. 처리 순서는 (백본 안) 마지막 층 토큰 출력에 최종 정규화 → 층마다 패딩 제외 토큰 평균으로 층 벡터 생성 → 층 벡터 단위로 층별 정규화다. 따라서 B0에서도 최종 정규화와 층별 정규화는 서로 다른 단계다.
   - B0: 마지막 층 벡터 → 선형 분류기
   - F1: 모든 층 벡터의 단순 평균 → 분류기
   - F2: 층마다 가중치 하나(데이터셋 전체에 하나의 묶음, softmax로 정규화) 가중합 → 분류기. 전체 스케일 계수 γ 없음. 전역 층만 / 지역 층만(임베딩 벡터 제외) 옵션
   - F3: 마지막 4개 층(19~22층) 층 벡터 이어붙이기 → 분류기
   - F4: 입력마다 달라지는 층 가중치로 가중합 → 분류기. 구체 형태는 미정("결정 필요 사항" 참고)
   - B0+: 마지막 층 벡터 → 2층 MLP(은닉 MNLI 26). ADR 0008의 "2클래스 25"는 B0+가 MNLI에서만 쓰이므로 현재 범위에서는 쓰이지 않는다
   - F2·F4의 층 가중치를 외부로 노출한다.
7. **실행 모듈 (실행 seam)** — `실행 설정 + 층 벡터 공급원 → 결과 레코드`. 학습률 후보 3개를 튜닝 분할로 평가해 하나를 고르고, 모든 결합 방식에 같은 에폭 수·같은 조기 종료 기준으로 학습한 뒤 평가셋에서 예측한다.
8. **재현 트랙 실행기** — 논문 설정 그대로 MNLI·SST-2 전체 데이터 파인튜닝 3회. 결과는 재현 트랙으로 표시해 본 실험 결과와 분리한다.
9. **대기열 실행기** — 본 실험 실행을 인프라 담당 한 사람이 한 번에 하나씩 순차 실행한다. 디버깅 실행은 대기열 밖에서 각자 돌리고 디버깅으로 기록된다.
10. **판정 모듈 (판정 seam)** — `결과 레코드 묶음 + 판정 규칙 문서 → 가설별 판정표`. 순수 함수. 디버깅 실행·재현 트랙 레코드는 판정에 넣지 않는다. 시드 평균·표준편차, 짝지은 McNemar, 길이 구간별 오차율, 최소 표본 기준, 무게중심, 전역 층 가중치 비율, 시드 일관성, F4 길이–가중치 순위 상관을 계산한다.
11. **보고 모듈** — 결과표(오차율 ± 표준편차, 학습 파라미터 수, 학습 시간), 학습 곡선, 층 가중치 그림, 길이 구간별 표, 시야 비율 표를 만든다.

### 데이터 형태 (계약)

- **실행 설정**: 데이터셋(MNLI/SST-2/IMDB) · 데이터 양 조건(전체/소량) · 결합 방식(B0/F1/F2/F3/F4/B0+) · 층 부분집합(전체/전역만/지역만, F2만) · 백본 조건(백본 고정/파인튜닝) · 입력 설정(IMDB만: L128/L512/Lfull) · 시드 · 학습률 후보 · 에폭 수 · 조기 종료 기준 · 실행 종류(본 실험/디버깅) · 트랙(본 실험/재현).
- **결과 레코드**: 실행 설정 · 학습률 선택 결과 · 평가셋 오차율(MNLI는 matched/mismatched 각각) · 문서 ID별 예측·정답 · 학습 파라미터 수 · 학습 시간 · 학습 곡선 · 층 가중치(F2, F4) · 소량 표본 문서 ID · transformers 버전·어텐션 구현·컴파일 설정.
- **캐시 생성 설정**: 모델 · 버전 · 길이(입력 설정, 상한) · 자르기 방식.
- **판정 규칙 문서**: 판정 기준 · 최소 표본 기준 · 시드 일관성 기준값. 11/30 고정, 이후 변경하지 않는다.

### 실험 행렬 (ADR에서 정해진 범위)

| 데이터 | 백본 조건 | 데이터 양 | 입력 설정 | 결합 방식 | 쓰는 가설 |
|---|---|---|---|---|---|
| MNLI | 고정 | 전체 | — | B0, F1, F2, F3, F4, B0+ | H1, H4′ |
| MNLI | 고정 | 소량 | — | 미정 | H2 |
| MNLI | 파인튜닝 | 전체 | — | B0, 가장 좋은 결합 방식 | H3 |
| SST-2 | 고정 | 전체 | — | 미정 (층 가중치 비교에 F2 필요) | H4(탐색) |
| IMDB | 고정 | 전체 | L128, L512, Lfull | B0, F1, F2 | H5a, H5b |
| IMDB | 고정 | 전체 | L128, L512, Lfull | F2 전역 층만 / 지역 층만 | H5c(탐색) |
| IMDB | 고정 | 전체 | Lfull | F4 | H5c(탐색) |
| MNLI, SST-2 | 재현 트랙 | 전체 | — | 논문 설정 × 3회 | 공개 수치 재현 |

### 그 밖의 결정 (근거)

- 백본은 ModernBERT-base 하나(ADR 0002). 선행연구와는 보고된 경향과의 정성 비교만 한다.
- transformers 버전, 어텐션 구현, 컴파일 설정을 각각 하나로 고정한다(ADR 0005).
- IMDB는 백본 고정만 하므로 입력 길이는 층 벡터 추출 단계에만 영향을 주고, 분류기 학습 배치는 세 입력 설정에서 같다(ADR 0004).
- B0+는 MNLI 본 실험에만 둔다(ADR 0008).
- 재현 트랙은 본 실험 B0 파인튜닝으로 대신하지 않는다(ADR 0004).

## 테스트 결정 (Testing Decisions)

### 좋은 테스트의 기준

- 바깥 행동만 검사한다. seam에 넣은 것과 나온 것만 보고, 내부 구현은 검사하지 않는다.
- 실행 seam과 판정 seam 테스트는 실제 GPU·실제 데이터 없이 돈다(가짜 층 벡터 공급원, 손으로 만든 결과 레코드). 실제 모델은 추출 확인 테스트에서만 쓴다.
- 테스트 하나가 ADR 규칙 하나를 드러내게 한다.

### Seam ① 실행 seam: `실행 설정 + 층 벡터 공급원 → 결과 레코드`

가짜 층 벡터 공급원으로 검사한다.

- 결합 방식별 학습 파라미터 수가 정의와 같고, B0+와 F4의 학습 파라미터 수가 맞춰져 있다.
- 한 층의 값 척도만 크게 바꿔도 층별 정규화 덕분에 F1의 결과가 바뀌지 않는다.
- F2에 전체 스케일 계수가 없다.
- 전역 층만 / 지역 층만 옵션에서 층 가중치가 각각 8개 / 14개이고 임베딩 벡터가 빠진다.
- 소량 조건에서 같은 시드의 모든 결합 방식이 같은 표본 문서 ID를 쓰고, 시드가 다르면 표본이 다르다. 표본은 클래스당 1,000건이다.
- 결합 방식이 달라도 학습률 후보 수·에폭 수·조기 종료 기준이 같다.
- 학습률은 튜닝 분할 결과로 고르며, 평가셋 라벨을 바꿔도 학습률 선택이 바뀌지 않는다.
- MNLI 결과 레코드에는 matched/mismatched 오차율이 각각 있다.
- 공급원의 생성 설정과 실행 설정이 다르면 오류가 난다.
- 결과 레코드에 학습 파라미터 수, 학습 시간, 학습 곡선, 문서별 예측, 실행 종류가 있다.

### Seam ② 판정 seam: `결과 레코드 묶음 + 판정 규칙 문서 → 가설별 판정표`

손으로 만든 결과 레코드로 검사한다.

- 차이 < 시드 간 표준편차이면 효과 없음.
- 차이가 표준편차보다 커도 McNemar가 유의하지 않으면 효과 없음.
- 둘 다 통과하면 지지.
- McNemar는 같은 문서끼리 짝지어 계산된다.
- 디버깅 실행·재현 트랙 레코드는 판정에 들어가지 않는다.
- 탐색적 가설(H4, H5c)에는 지지/효과 없음 판정이 붙지 않는다.
- 시드 일관성 기준에 못 미치면 층 가중치 해석이 보류된다.
- 무게중심·전역 층 가중치 비율이 손으로 계산한 값과 같다(예: 22층에 가중치가 모두 실리면 무게중심 22, 전역 층 가중치 비율 1).
- H5b 보고에 섞기 효과(F1 − B0)와 가중치 학습 효과(F2 − F1)가 나뉘어 나온다.

### Seam ③ 추출 확인 테스트 (실제 ModernBERT, 짧은 입력 몇 개)

고정한 버전에서 실행한다.

- 문서당 층 벡터가 23개이고, 마지막 층 벡터가 최종 정규화된 출력의 토큰 평균과 같다.
- **캐시 형태와 순서**: 캐시가 [문서 수, 23, 768]이고, 문서 ID·라벨 순서가 원본과 일치한다.
- **패딩 제외**: 평균 풀링에서 패딩이 제외된다. 같은 문서는 패딩 양이 달라도 층 벡터가 같다.
- **자르기 길이**: L128 = 앞 32 + 뒤 94, L512 = 앞 128 + 뒤 382, 특수 토큰 포함 128 / 512.
- **짧은 문서 동일성**: 512보다 짧은 문서는 L512와 Lfull 벡터가 같다.
- **생성 설정 기록**: 캐시 파일에 생성 설정(모델·버전·길이·자르기 방식)이 기록되고, 실행할 때 설정과 다르면 오류가 난다.

### 보조 단위 테스트

- 시야 비율: GLOSSARY 정의(앞뒤 64토큰씩, 자신 포함 129토큰)로 계산하면 길이 128 문서의 평균이 약 0.754로, ADR 0006의 "약 75%"와 맞는다. 129토큰 이하 문서는 1.0이다.
- 길이 구간 경계: 512는 ≤512, 513과 1,024는 512~1,024, 1,025는 1,024 초과에 들어간다.

### 선행 사례

새 저장소라 기존 테스트는 없다. 위 세 seam 테스트가 이후 테스트의 본보기가 된다.

## 결정 필요 사항

근거 문서에서 아직 정해지지 않은 항목이다. 모두 **본 실험 실행 전에** 고정해야 한다. 디버깅 실행으로 정해도 되지만, 본 실험 결과를 본 뒤에 정하면 안 된다.

### 1주차 확인으로 정해지는 것 (측정·확인)

- transformers 버전(5.x 중), 그 버전에서 층별 출력 목록의 마지막 값 정의 (ADR 0005)
- 어텐션 구현(Flash Attention / SDPA)과 컴파일 설정 (ADR 0005)
- Lfull 상한: IMDB 최대 토큰 길이를 센 뒤 결정 (ADR 0006)
- 교수님 승인: MNLI·SST-2 사용 가능 여부 (ADR 0003)

### 11/30 판정 규칙 문서에 고정할 것 (ADR 0007)

- 최소 표본 기준, 그리고 기준에 못 미치는 길이 구간을 어떻게 표시할지
- 시드 일관성 기준값(순위 상관 하한, 무게중심 표준편차 상한)
- McNemar 유의수준, 여러 결합 방식을 B0와 비교할 때 다중 비교 보정 여부
- 시드가 여러 개(3·5시드)일 때 McNemar를 어떻게 적용할지: 결과 레코드는 시드마다 하나씩 나오므로, 여러 시드의 문서별 예측을 하나의 판정으로 묶는 방법이 필요하다
- 무게중심과 전역 층 가중치 비율을 계산할 때 임베딩 벡터의 가중치를 어떻게 다룰지: GLOSSARY상 임베딩 벡터는 층 번호가 없고("0층" 금지) 전역/지역 층에도 속하지 않아, 무게중심의 층 번호와 전역 층 가중치 비율의 분모가 정해지지 않았다. 무게중심은 시드 일관성 기준에도 쓰이므로 여기서 함께 고정한다
- 핵심 비교 목록(5시드 대상). 파인튜닝 조건의 시드 수도 여기서 정해진다
- H1을 판정할 결합 방식(F1~F4 중 하나라도 이기면 지지인지, 대표 방식 하나로 판정하는지)
- H5a를 판정할 결합 방식
- 파인튜닝 조건에 쓸 "가장 좋은 결합 방식"을 고르는 기준

### 구현 단계에서 정할 것

- F4의 구체 형태(게이트 구조와 입력 벡터). 참고로, 게이트를 768차원 입력에서 23개 가중치를 내는 선형층으로 두고 분류기를 선형으로 두면 F4 학습 파라미터는 MNLI 19,994개 / 2클래스 19,225개이고, B0+는 은닉 26에서 20,075개 / 은닉 25에서 19,277개다. ADR 0008의 은닉 크기와 맞는 계산이지만 결정된 형태는 아니다.
- F2·F4 층 가중치의 정규화 방식(예: softmax 여부) → **F2 결정(2026-11-19, T-05a, 차가원 PR 승인으로 확정): softmax.** 층마다 학습 로짓 하나를 두고 softmax로 가중치를 만든다(양수, 합 1). 근거: 가중치 합이 1이라 전체 스케일 계수 γ를 두지 않는 ADR 0005와 맞고, 무게중심·전역 층 가중치 비율이 그대로 정의된다. 로짓은 0으로 초기화해 학습 시작 시 F2 = F1이다. **F4는 미정**: softmax를 전제로 하되 게이트 구조와 함께 T-05b에서 확인한다.
- 토큰 평균에 특수 토큰을 포함할지
- 학습률 후보 3개의 값, 에폭 수, 조기 종료 기준, 배치 크기, 파인튜닝 조건의 학습률 범위
- 튜닝 분할을 나누는 방식(분할을 하나로 고정할지 등)
- 소량 표본을 뽑는 범위(튜닝 분할 포함 여부)와 소량 조건의 학습률 선택에 쓸 튜닝 분할
- MNLI 소량 조건과 SST-2에서 돌릴 결합 방식 목록
- 학습 시간 측정 범위(층 벡터 추출 시간 포함 여부)
- 파인튜닝 조건에서 보고할 파라미터 수의 범위(백본 포함 여부)
- B0+와 F4 파라미터 수의 허용 차이
- MNLI가 거절되어 AG News(4클래스)로 바꿀 경우의 B0+ 은닉 크기. ADR 0008은 MNLI 26 / 2클래스 25만 정했다
- 층 벡터 캐시 저장 정밀도. 참고: MNLI 학습셋 캐시는 float32로 약 28GB, float16으로 약 14GB다.

## 추가 메모 (Further Notes)

- **일정 기준점**: 1주차 확인(위 목록) → 11/30 판정 규칙 문서 고정 → 본 실험 → 12/14 최종 발표(보고서 4~6쪽, 코드, 발표).
- **우선순위**: 일정이 밀리면 MNLI > SST-2 > IMDB(ADR 0003). 1~4순위 가설(H1 > H3 > H2 > H4′)이 MNLI 하나로 판정되므로 IMDB가 늦어져도 핵심 결론은 지켜진다(ADR 0007).
- **지표**: 결과 보고와 판정은 오차율(낮을수록 좋음)로 통일한다(PDF, GLOSSARY). 논문 공개 수치처럼 정확도로 된 값은 오차율을 함께 적는다.
- **ADR 간 표현 불일치**: ADR 0003은 "SST-2는 층 가중치(무게중심)로 판정"한다고 적었지만, ADR 0007은 H4를 탐색적 가설로 두었고 GLOSSARY는 탐색적 가설을 "판정하지 않고 경향만 보고"한다고 정의한다. 이 명세는 ADR 0007·GLOSSARY를 따랐다. ADR 0003 문구 정리가 필요하다.
- **보고서 한계 절 후보**: B0+는 파라미터 수만 같고 형태가 다름(ADR 0008), 전역/지역 ablation의 층 수 차이 가정과 "출력의 쓸모" 해석(ADR 0006), F4는 "게이트가 길이에 반응한다"까지만 주장(ADR 0006), 선행연구 비교는 정성 비교(ADR 0002), 시드 표준편차는 평가셋 흔들림을 반영하지 못해 McNemar를 더함(ADR 0007).
