# 본 실험은 백본 고정이 기본이고, 재현은 별도 트랙으로 돌린다

---
status: accepted
---

모든 결합 방식 비교와 ablation은 **백본 고정 조건**에서 하고, 파인튜닝 조건은 핵심 비교(B0 vs 가장 좋은 결합 방식)에만 반복한다. 백본을 고정하면 결합 방식만 달라져서 효과의 원인이 깔끔하게 분리되고, 층 벡터를 한 번만 추출해 두면 시드 반복이 값싸다. 파인튜닝 반복을 남겨 둔 건, "파인튜닝하면 결합 효과가 줄거나 사라진다"(H3)를 검증하고 파인튜닝 대비 향상폭을 보이기 위해서다.

공개 수치 재현(MNLI 89.1, SST-2 96.0)은 **재현 트랙**으로 따로 돌린다. 논문 설정 그대로 전체 데이터를 파인튜닝하고 3회 실행한다. 본 실험의 B0는 층별 정규화와 선형 분류기를 쓰므로 논문의 분류 헤드와 구성이 달라서, 파인튜닝 B0 실행이 재현을 겸할 수 없다.

## Considered Options

- **파인튜닝을 메인으로**: 백본도 같이 변해서 결합 모듈의 효과와 백본 적응 효과가 섞이고, 파인튜닝한 모델은 이미 성능이 높아 향상폭이 표준편차보다 작아지기 쉽다.
- **백본 고정만**: 가장 단순하지만, H3와 파인튜닝 대비 향상폭을 보일 수 없다.

## Consequences

IMDB 길이 비교는 백본 고정만 한다. 그래서 입력 길이는 층 벡터 추출 단계에만 영향을 주고, 분류기 학습 배치는 세 입력 설정에서 자동으로 같아진다(gradient accumulation이 필요 없다).
