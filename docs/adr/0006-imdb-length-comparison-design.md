# IMDB 길이 비교는 같은 자르기 비율로 L128 / L512 / Lfull을 비교한다

---
status: accepted
---

IMDB에서는 입력 설정 세 가지를 비교한다. **L128**(앞 32 + 뒤 94), **L512**(앞 128 + 뒤 382, Sun et al. 원래 설정), **Lfull**(상한까지 자르지 않음)이고, 길이는 특수 토큰을 포함한 값이다. L512는 "BERT 계열의 기본 상한과 같은 길이"라는 의미를 정확히 하려고 512에 맞췄고, 긴 입력의 효과(H5a)는 L512와 Lfull을 비교해야 검증된다. 짧은 두 설정도 앞+뒤 비율을 같게 맞춰서, 세 설정의 차이를 **길이 하나**로 한정했다.

## Considered Options

- **128 vs 512만 비교**: 512는 BERT도 처리하는 범위라 ModernBERT의 긴 입력 능력을 시험하지 못한다.
- **앞부분만 자른 512를 기준선으로(S1)**: 리뷰 결론부의 감성 단서를 잃어서 Lfull의 이득이 부풀려진다. "어떻게 자르는 게 좋은가"는 연구 질문도 아니다.
- **MNLI와 IMDB를 직접 비교**: 과제 차이와 길이 차이가 섞인다(ADR 0003).

## Consequences

- **Lfull 상한**: ModernBERT 토크나이저로 최대 길이를 센 뒤 정한다. 4,096 이하면 잘리는 문서가 없고, 넘으면 4,096을 유지하고 잘린 문서 비율을 보고한다.
- **오차율 보고**: L512 vs Lfull은 길이 구간별(≤512 / 512~1,024 / 1,024 초과)로 보고한다. ≤512 구간은 두 설정의 입력이 같으므로 정상 작동 확인용이다. 최소 표본 기준은 판정 규칙 문서에서 확정한다.
- **시야 비율 표현**: 시야 비율은 문서마다 다르므로 숫자 하나로 쓰지 않고 길이 구간별로 제시한다. 지역 창은 앞뒤 64토큰씩이라, L128도 "완전히 같은 시야"가 아니다. 보고서에서는 "지역 층이 입력 대부분(평균 약 75%)을 보는 대조군"으로 표현한다.
- **전역/지역 ablation**: F2를 전역 층 8개만 / 지역 층 14개만으로 학습해서 비교한다. 임베딩 벡터는 양쪽 모두에서 뺀다. 지역 층은 앞쪽 전역 층의 출력을 입력으로 받으므로, 이 비교는 "어느 종류 층의 **출력**이 분류에 더 쓸모 있나"로 해석한다. 길이별 격차 비교로 층 수 차이(8 vs 14)를 상쇄한다는 건 "층 수 효과가 길이와 무관하다"는 가정이며, 보고서 한계에 적는다.
- **F4 보조 분석**: Lfull에서만 F4를 학습하고, 문서 길이와 문서별 전역 층 가중치 비율의 순위 상관을 라벨별로도 보고한다(탐색적). L128과 L512에서는 긴 문서가 같은 길이로 잘려서 길이 변수가 상한에서 멈추므로 제외한다. "게이트가 길이에 반응한다"까지만 주장하고 인과 해석은 하지 않는다.
