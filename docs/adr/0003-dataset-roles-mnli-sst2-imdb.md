# 데이터는 MNLI(메인), SST-2(과제 비교), IMDB(길이 비교)로 역할을 나눈다

---
status: accepted
---

PDF의 승인 불필요 목록(AG News, IMDB 등) 대신 **GLUE의 MNLI를 메인**으로 골랐다. ModernBERT의 공개 재현 수치가 있고, 백본 고정 성능과 파인튜닝 성능의 격차가 커서 층 결합 효과(H1)와 파인튜닝 시 효과 변화(H3)를 검출하기 좋으며, matched/mismatched 평가셋으로 일반화(H4′)까지 추가 학습 없이 볼 수 있기 때문이다. **SST-2**는 추론과 감성 과제의 차이(H4)를 보는 용도로만, **IMDB**는 같은 데이터 안에서 입력 길이만 바꾸는 비교(H5)에만 쓴다.

## Considered Options

- **AG News 메인 + IMDB 보조**: 승인 리스크가 없지만, ModernBERT 공개 수치가 없어 재현을 우회해야 했다.
- **MNLI + IMDB를 과제 비교에 사용**: IMDB는 리뷰가 길어서, MNLI와 비교하면 과제 차이와 길이 차이가 섞인다. 그래서 과제 비교는 짧은 문장인 SST-2로 하고, IMDB는 IMDB 안에서만 길이를 비교한다.
- **MNLI 단독**: 가장 깊게 팔 수 있지만, H4(과제 비교)와 길이 분석을 잃는다.

## Consequences

- GLUE 테스트 정답은 비공개다. 그래서 MNLI·SST-2는 공개 validation을 **평가셋**으로 쓰고, 학습셋의 10%를 **튜닝 분할**로 뗀다. 논문 수치도 validation 기준이라 비교 조건이 같다.
- SST-2는 라이선스가 표기되어 있지 않고 GLUE는 승인 목록 밖이라, 교수님께 MNLI와 SST-2를 확인받는다. 승인되지 않으면 SST-2는 제외하고, MNLI가 거절되면 AG News로 전환한다.
- SST-2 평가셋은 872건이라 정확도 비교가 흔들린다. 그래서 핵심 결론(H1~H3)은 MNLI로만 내리고, SST-2는 층 가중치(무게중심)로 판정하며, 정확도 비교에는 McNemar 검정을 쓴다.
- 일정이 충돌하면 MNLI > SST-2 > IMDB 순으로 우선한다.
