# 연구 대상은 "같은 입력의 서로 다른 층 표현 결합"이다

---
status: accepted
---

PDF의 세 트랙 가운데 가산점이 있는 Track A(고차원 구조 설계)를 골랐다. 결합 대상은 **같은 입력 하나에서 나온 서로 다른 층의 층 벡터**다. 두 문장을 따로 인코딩한 벡터(u, v)를 결합하는 설계가 아니다. PDF의 Track A 질문 예시가 "중간층과 마지막 층의 Latent Vector를 가중합으로 결합"이고, 이렇게 하면 문장이 하나인 과제(SST-2, IMDB)에도 같은 실험을 그대로 적용할 수 있다.

## Considered Options

- **Track B(구조 요소 분석)**: 깊이별로 모델을 처음부터 여러 번 학습해야 해서 GPU 시간이 가장 많이 들고, 이미 답이 알려진 결과의 재현에 가깝다.
- **Track C(학습 전략 비교)**: 실패 위험은 가장 낮지만, 성능 개선 항목이 "결론의 명확성"으로 바뀌고 가산점이 없다.
- **문장 쌍 벡터 결합(u, v, |u−v|)**: 문장 쌍 과제로만 데이터가 제한되고, 두 문장을 따로 인코딩하면 GLUE 공개 수치(두 문장을 이어 붙여 한 번에 넣는 방식)와 비교할 수 없게 되며, Sentence-BERT가 이미 정리한 주제다.

## Consequences

MNLI의 두 문장도 [SEP]으로 이어 붙인 **하나의 입력**으로 처리한다. 따라서 MNLI와 SST-2는 결합 구조가 같다.
