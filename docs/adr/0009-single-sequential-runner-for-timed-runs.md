# 본 실험 실행은 한 사람이 순차로만 돌린다

---
status: accepted
---

RTX 5090은 메모리가 32GB라 여러 작업을 동시에 올릴 수 있지만, 본 실험 실행은 인프라 담당(차가원) 한 사람이 대기열로 **한 번에 하나씩** 돌린다. 한 GPU에서 여러 프로세스가 돌면 GPU가 시간을 쪼개 번갈아 실행해서 학습 시간이 늘어나고, PDF가 결과표에 요구하는 학습 시간 수치를 설정끼리 비교할 수 없게 된다. 연구실 공용 서버라 다른 사람의 작업과 겹치는 것도 막아야 한다. 디버깅 실행은 각자 계정으로 동시에 돌려도 된다.
